# 글로벌 실사 가이드 — S6 확장 (경로 B)

**목적**: 해외 후보 8종목에 국내와 **같은 실사 규칙**을 적용해
`data/processed/글로벌후보_실사_20260729.csv`를 채운다.
판정 주체는 사용자다 — 코드는 판정하지 않고 검증만 한다.

## 대원칙 (국내 실사와 동일)

1. **fail-closed** — 공시 문서에 근거가 없으면 그 칸은 빈칸으로 둔다.
   빈칸인 종목은 편입되지 않는다. "앞으로 연관될 것"은 전망이지 요건이 아니다
   (심텍·SFA를 관찰로 돌린 것과 같은 잣대).
2. **문턱 무수정** — 핵심 30%·위성 70%·앵커(메모리제조×HBM양산) 그대로.
   해외 종목이라고 규칙을 구부리지 않는다. TSMC가 어느 군에도 못 들면
   그것이 규칙의 판정이다.
3. **한 파일이 단일 출처** — 실사 결과는 위 CSV 하나에만 기록한다.
   (관찰종목 코드 복사 사고의 교훈.)

## 컬럼 규약

| 컬럼 | 규약 |
|---|---|
| 시가총액·유동시총·거래대금 | **억 원(KRW 환산)**. 환산에 쓴 날짜를 `환산기준일`에 기록 |
| FF | 0~1 (free float 비율) |
| HBM노출도·메모리향비중 | **0~1** — 35%면 `0.35`. `35`로 쓰면 로더가 오류를 낸다 |
| HBM양산 | 메모리 제조사가 HBM을 실제 양산·공급하면 True (앵커 결합 요건) |
| HBM공정확인 | TSV·하이브리드본딩 등 HBM 고유공정 귀속 매출의 **문서 확인** |
| 위원회확인 | ①②의 문서 충족 여부 확인 (재량 없음 — 국내와 동일) |
| 감사의견 | unqualified → `적정`, qualified → `한정`, adverse → `부적정`, disclaimer → `의견거절` |
| 자본잠식 | 최근 분기 자본총계 ≤ 0 이면 True |
| 관리종목 | 상장폐지 심사·거래정지 등 거래소 조치 중이면 True |
| 거래대금 | 최근 60거래일 일평균 (KRW 환산 억 원) |

## 종목별 확인 포인트

### MU — Micron Technology (HBM 제조)
- **10-K** Part I(Business)·Part II Item 7(MD&A): DRAM 매출 내 HBM 언급,
  HBM3E/HBM4 양산·공급 공시.
- 앵커 후보: `유형=메모리제조` + `HBM양산=True`면 앵커 — 세계 HBM 3사 중
  유일한 비편입사라 실사 근거는 풍부할 것.
- 메모리향비중: DRAM+NAND가 매출 대부분 → 1.0에 가까움 (10-K 세그먼트 표).

### TSM — TSMC (로직다이·CoWoS)
- **20-F**: HBM 자체를 만들지 않는다. CoWoS/SoIC 어드밴스드 패키징 매출이
  HBM 귀속인지, 전체 매출 대비 몇 %인지.
- ⚠ 예상: 노출도 30% 미만 + 메모리향 70% 미달 → **미편입이 규칙의 판정**일
  가능성이 크다. 그래도 실사는 한다 — "왜 없나"에 문서로 답하기 위해.

### BESI.AS — BE Semiconductor (하이브리드 본딩)
- **Annual Report**: hybrid bonding 장비 수주·매출 비중. HBM4부터 하이브리드
  본딩 전환이 핵심 논점 — '수주'와 '매출'을 구분해 매출 기준으로 판정.
- 메모리향비중: 고객 구성(로직 패키징도 큼)을 문서로 — 70% 문턱이 관건.

### 0522.HK — ASMPT (TC 본더)
- **Annual Report**: advanced packaging 부문 중 TCB 매출. 한미반도체의 직접
  경쟁사 — 한미에 적용한 것과 같은 눈높이로 귀속 매출을 본다.

### 6857.T — Advantest (메모리 테스터)
- **유가증권보고서**: 메모리 테스터 매출 비중(HBM 테스트 수요 급증 언급).
- 메모리향비중 70%가 관건 — SoC 테스터 매출이 크면 미달. 세그먼트 표 기준.

### CAMT — Camtek (검사)
- **20-F**: HBM/어드밴스드 패키징 검사 장비 수주 공시 다수 — 매출 귀속 비율로.

### ONTO — Onto Innovation (계측)
- **10-K**: advanced packaging 계측 매출. 2019 합병 상장이라 2018 위기 표본
  없음(스캔에서 '표본부족'으로 표시됨).

### 4004.T — Resonac (HBM 소재)
- **유가증권보고서**: 반도체 소재 부문 중 HBM 귀속(NCF 등 접착 소재).
  대형 화학사라 반도체 부문 자체가 전체의 일부 — 메모리향 70%는 전사 매출
  기준이면 미달 가능성. **전사 기준으로 판정한다** (국내도 전사 기준이었다 —
  솔브레인 메모리향 0.70이 전사 기준).

## 제외 종목 (등록부에 없는 이유 — `EXCLUDED`)

- NVIDIA·AMD: 수요측. HBM을 사는 쪽이지 밸류체인 공급망이 아니다.
- AMAT·LRCX·TEL: 전공정 광의 — 노출도 30% 구조적 미달.
- Teradyne: 메모리 테스트 비중 낮음. Amkor: HBM 조립은 메모리사 내재화.

새 종목을 넣고 싶으면 `global_candidates.CANDIDATES`에 체인구간 근거와 함께
등록부터 한다 — 등록 없는 티커는 실사 CSV에 있어도 로더가 거부한다(테마 가드).
